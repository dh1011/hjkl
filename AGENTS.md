# Skill learning workflow

- The skill picker selects the course. Start runs the selected skills; do not add a separate Resume path or bypass teaching with independent practice batches.
- Progress stays in memory by default. The opt-in **Remember progress** setting (off by default) saves the run to `localStorage` and a reload reopens it directly, without a Resume screen. Turning it off deletes the saved copy; stale or unreadable saves start fresh.
- Every skill must follow two guided edits, two prompted edits, then two independent edits, in that order.
- Guided means a text/key hint below the editor that follows the current edit. Prompted means an initial hint below the editor that disappears once editing begins. Independent edits have no automatic hint; manual hints remain available.
- The off-track undo prompt is guided-only; prompted and independent edits show no recovery prompt.
- Animation, floating keys, cursor effects, and selection outlines are not substitutes for bottom guidance. Do not use an animated cue instead of the bottom hint for any skill, including the first typo lesson.
- Keep long skill goals concise in every assistance stage: show only changed lines, with removed text struck through and added text highlighted. Use the same goal presentation for guided, prompted, and independent lessons; do not repeat the entire document above the editor.
